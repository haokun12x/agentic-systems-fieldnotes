MODEL-DRIVEN ADAPTATION

A weak hit changes the query.

The prompt asks the Agent to refine keywords, category, or format when candidates are weak. A structured tool error is another observation; the model may choose a different call or explain the gap.

ADAPTER-LEVEL RECOVERY

A retry is a different mechanism.

The business API adapter can refresh a rejected service token and repeat its call once. ASR/OCR default to at most three attempts with backoff; HTTP 4xx errors stop immediately. These adapter retries do not replan the user’s task.

IMPLEMENTATION / HARDENING

A graph ceiling is not a retry budget.

The inspected configuration sets a 999-step recursion ceiling. Per-task deadlines, model-call budgets, and a common retry policy are additional hardening—not guarantees provided by this exhibit.

The harness supplies capabilities; the model chooses among them. The inspected construction combines create_deep_agent, registered tools, three storage routes, a general-purpose library subagent, and a custom transcription role. Planning is optional.
