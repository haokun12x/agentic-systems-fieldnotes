// One authorized, contiguous public stream per run.
function apply(view, raw) {
  const event = validateV1(raw); // type + payload schema
  if (event.run_id !== view.runId) return view;
  if (event.seq <= view.cursor) return view; // duplicate
  if (event.seq !== view.cursor + 1) return requestResync();
  const next = projectAllowedEvent(view, event);
  return { ...next, cursor: event.seq };
}

The browser owns presentation.

request_id correlates the command; thread_id identifies authorized conversation state; run_id names one execution; seq orders this public stream. Private traces use a separate sequence.

Validate supported schema versions before reduction. Unknown event types trigger an explicit compatibility policy. Render text as text, sanitize approved markup, and allowlist artifact renderers. Never render raw tool HTML.

A new page load restores an authorized snapshot and resumes after its cursor. Native EventSource sends Last-Event-ID on its own reconnect; application-managed reconnects must explicitly carry their saved cursor in a supported request parameter.
