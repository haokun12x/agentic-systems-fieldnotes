WHO CHOOSES?

The model emits tool-call names and arguments. Deep Agents / LangGraph dispatches those calls, adds observations to state, and invokes the model again. A system prompt guides choices; it does not make every branch deterministic.

WHERE DOES IT LIVE?

Root files such as /plan.md and /final_report.md use the graph StateBackend. /workspace/ resolves to a thread’s disk directory. /knowledge/ is a separate read-only disk view.

WHAT IS A RETRY?

A model may revise arguments after a failed result. The business connector separately retries once after its recognized token-authentication response. UI export and voice-input failures return errors to the user; they do not automatically create another agent run.
