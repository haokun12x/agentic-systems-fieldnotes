When this architecture earns its place

One team needs a ready application. Start with a platform or an established harness that fits the task.

Many departments share infrastructure and private systems. Explicit scope, resource ownership, retention, and connector contracts become product requirements.

Work must survive overload, worker loss, or ambiguous writes. Recovery and dispatch semantics become part of correctness.

Deployment or runtime needs to change. Stable adapters and independently validated software/accelerator boundaries preserve choice.

Evidence behind the position: the checked application supplies department/browser boundaries, three storage routes, tools, and UI transport. The Rust kernel demonstrates selected execution semantics. Replicated recovery, policy-controlled writes, and search controllers have explicit implementation paths in this architecture.
