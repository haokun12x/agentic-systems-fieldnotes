Why these strategies fit the same execution model

State extension. A plan adds pending steps; reflection adds feedback memory; tree search adds candidates, parent links, and visit/value statistics. Each is explicit strategy state.

Action interpretation. Model calls, retrieval, evaluators, and delegated tasks produce observations through defined adapters. The controller decides which observation it needs next.

Policy composition. A plan step can invoke a reactive controller; a search branch can invoke an evaluator or delegate. Their local states and stop rules remain identifiable.

Execution invariants. Scope, accepted observations, resource budgets, resumable state, and effect authorization are enforced around each controller. Expressing an algorithm preserves its own selection/evaluation rules.

This is a constructive architecture mapping: define the required state and controller, then bind it to the runtime contracts. Algorithm fidelity, task quality, and operating guarantees are validated separately.
