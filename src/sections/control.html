CROSS-DEPARTMENT WORK
Coordination needs
an explicit handoff.
Current boundary: switching departments selects another backend, knowledge root, and browser-scoped history. All department processes load the same orchestrator and tool registry. A general-purpose subagent is not a cross-department superuser; no dedicated cross-department delegation tool is registered.
Office request→Authorized data request→Other department→Reviewed evidence
PRODUCTION EXTENSION A coordinator would obtain separately authorized, minimal results from each source department, preserve provenance, and recheck access before sharing. This handoff is an architecture target, not an existing call path.
